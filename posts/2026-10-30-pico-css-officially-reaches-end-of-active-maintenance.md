Pico CSS, the minimal framework popular among web builders, is no longer actively maintained. The project team confirmed the status update in a recent GitHub discussion.

While existing setups will continue to run without immediate breaking changes, developers should plan ahead:
- Explore alternative lightweight styling tools
- Monitor community discussions for potential forks
- Audit current projects using the framework

The announcement has sparked widespread discussion across developer forums as the community reflects on the framework's future.
