A notable security concern remains unaddressed for developers using Apple hardware. Ten days after initial reports, Git installations on macOS are still actively trusting compromised eMudhra certificates.

This delay in revoking trust leaves default developer environments exposed to potential certificate-related risks during secure operations.

Key points:
- Affects Git on macOS systems
- Involves compromised eMudhra root certificates
- Unresolved ten days after detection
