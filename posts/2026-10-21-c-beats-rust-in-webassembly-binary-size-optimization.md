WebAssembly developers traditionally rely on Rust when minimal binary footprints are required. However, recent developments in the ecosystem show that C# is making massive strides in payload optimization.

According to findings in the NetWasm project, C# compilation now yields smaller WebAssembly file sizes than Rust. This milestone highlights significant progress in the .NET web runtime pipeline.

Highlights of this shift include:
- C# achieving smaller overall WASM outputs
- Increased competition in lightweight web runtimes
